# UNISELL 🛒

A modern e-commerce website built using HTML, CSS, and JavaScript featuring product browsing, cart management, checkout simulation, dark mode support, and analytics integration.

## 🌐 Live Demo

https://nikunjmody05.github.io/UNISELL/

---

## ✨ Features

* Product Catalog
* Shopping Cart using Local Storage
* Dark / Light Theme
* Product Search
* Category Filtering
* Full Checkout Flow
* UPI Payment Simulation
* Debit / Credit Card Payment Simulation
* Order Summary
* Responsive Design
* Google Analytics 4 Integration
* Microsoft Clarity Integration

## 📊 Analytics Events

The project tracks user interactions using Google Analytics 4.

| Event            | Description                  |
| ---------------- | ---------------------------- |
| add_to_cart      | User adds a product          |
| begin_checkout   | Checkout process started     |
| add_payment_info | Payment method selected      |
| purchase         | Order successfully completed |
